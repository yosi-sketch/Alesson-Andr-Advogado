# Ione Barcelos — Advogada

Landing page e site institucional de alto padrão desenvolvido em Next.js 16 (App Router), Tailwind CSS v4 e Framer Motion para **Dra. Ione Barcelos — Advocacia Trabalhista**, com atuação no Vale do Aço (Coronel Fabriciano, Ipatinga, Timóteo e região) e em todo o Brasil.

## 🛠️ Tecnologias Utilizadas

- **Framework:** Next.js 16 (App Router)
- **Estilização:** Tailwind CSS v4 (@tailwindcss/postcss)
- **Tipografia:** Cormorant Garamond, Playfair Display, Cinzel, Plus Jakarta Sans (Google Fonts)
- **Animações:** Framer Motion
- **Ícones:** Lucide React
- **SEO & Metadados:** JSON-LD Schema.org LegalService, OpenGraph, Favicon multi-resolução e Viewport configurados
